# FlexTracker

A customizable tracker + bookmark manager built with HTML, Tailwind CSS, vanilla JavaScript, and Firebase.

---

## 🚀 Overview

FlexTracker is a lightweight web app that allows users to create their own trackers (like mini spreadsheets) and manage structured data such as:

* Internship applications
* Expenses
* Study plans
* Bookmarks / resources

Users can define their own columns and add rows dynamically.

---

## ✨ Features (MVP)

* Create multiple trackers
* Custom columns (text, number, link)
* Add and view rows dynamically
* Responsive table UI
* Simple modals (Add Column / Add Row)
* Clean SaaS-style UI (Tailwind)

---

## 🧱 Tech Stack

* HTML
* Tailwind CSS (CDN)
* Vanilla JavaScript
* Firebase (Auth + Firestore)
