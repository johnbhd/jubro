About Jubro

Built For Students, Freelancers & Job Seekers

Jubro is a simple job application tracker designed to help people organize applications, interviews, and opportunities without complicated dashboards or messy spreadsheets.

Whether you're applying for internships, freelance projects, remote work, or full-time jobs, Jubro keeps everything organized in one clean and beginner-friendly workspace.

How to Use Board Views

Switch between a focused list view and a spreadsheet-style table view inside each tracker board.

Use table view when you need quick editing, then switch to list view when you want a cleaner reading layout for each application.
